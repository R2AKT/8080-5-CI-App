📋 Обзор программы

i8080-5 CI (i8080-5 Control Interface) — комплексная среда для работы с процессором Intel 8080:

  • 🖥️ Эмулятор i8080 — все 256 инструкций, включая недокументированные
  • 🐛 Отладчик — breakpoints (обычные и условные), Run to Cursor, Watch-окна
  • 📜 Трассировка — запись каждой инструкции с состоянием регистров
  • 🔧 Hex-редактор — редактирование памяти с подсказками мнемоник
  • 📖 Дизассемблер — со стрелками переходов и цветовой подсветкой
  • 🔌 Работа с устройством — чтение/запись памяти и IO через COM-порт
  • 🤖 MCP-сервер — интеграция с AI-ассистентами

⚙️ Установка и запуск

Зависимости

pip install PySide6 pyserial

Для MCP: pip install mcp uvicorn starlette pydantic pydantic-settings

Запуск

python i8080_CI.py

🔌 Работа с устройством

Порядок работы

  1. Выберите COM-порт и скорость
  2. Нажмите «Подключиться»
  3. Нажмите «Захватить шину (HOLD)» и дождитесь подтверждения
  4. Выполняйте операции чтения/записи
  5. Нажмите «Освободить шину (UnHOLD)» для возврата управления процессору
⚠️ Внимание: перед операциями чтения/записи памяти устройства необходимо захватить шину. При закрытии программы шина освобождается автоматически.
