# Примеры ассемблера i8080

Каталог с тестовыми проектами, демонстрирующими возможности встроенного
двухпроходного ассемблера Intel 8080: одиночные файлы, все директивы,
макросы и многофайловая сборка с линковкой.

## Структура

| Каталог | Что демонстрирует |
|---------|-------------------|
| `01_hello/` | Минимальная одиночная программа (ORG, метки, подпрограмма, DB, HLT) |
| `02_directives/` | Все директивы: ORG, EQU, #define, #include, #path, #if, MACRO, REPT, DB, DW, DS, метки |
| `03_macros/` | Макросы с параметрами, вложенные макросы, REPT, условная сборка |
| `04_multifile/` | Многофайловая сборка: EXPORT/IMPORT, объектные файлы, линковка, map-файл |

## Как собрать

Сборка **всех** примеров (запускает `build.py` каждого каталога и сводит итог):

```
python assembler_example/build_all.py
```

Сборка **отдельного** примера:

```
python assembler_example/01_hello/build.py
python assembler_example/02_directives/build.py
python assembler_example/03_macros/build.py
python assembler_example/04_multifile/build.py
```

Каждый `build.py`:
1. Ассемблирует `.asm` файл(ы) через `assemble8080.assembler.assemble()`.
2. Сохраняет бинарник (`.bin`) и/или объектные файлы (`.obj`).
3. Для многофайлового примера — слинковывает по `.lnk`-скрипту.
4. Проверяет результат (ожидаемые байты, символы, патчи relocation) и печатает `[OK]`/`[FAIL]`.

## Результаты сборки

- `01_hello/hello.bin` — 25 байта, программа вывода строки.
- `02_directives/directives.bin` — 37 байта, демонстрация всех директив.
- `03_macros/macros.bin` — 29 байта, макросы и REPT.
- `04_multifile/app.bin` + `app.map` — слинкованный образ (main @ 0x0100, helper @ 0x0200).

## Зависимости

Примеры используют пакет `assemble8080` из корня проекта. Путь добавляется
автоматически в `_common.py` — запускать можно из любого каталога.
